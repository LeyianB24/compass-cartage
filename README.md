# Compass Cartage Web Platform

A high-performance relocation and logistics web application for Compass Cartage based in Edmonton, Alberta.

## Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Tech Stack

- Next.js 16 (App Router)
- React 19
- Tailwind CSS v4
- Prisma 7 & Neon Postgres
- Resend Transactional Email
- Vercel Blob Storage
